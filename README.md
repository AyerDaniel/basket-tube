# BasketTube — AI Basketball Game Analyzer                                                                                                                                                  
   
  **Daniel Ayer — DS681 NJIT**                                                                                                                                                                
                       
  AI-powered basketball game analysis using computer vision and vision-language models.                                                                                                       
  Analyzes a Lakers vs. Warriors broadcast game through two complementary approaches:
  commentary-based Q&A (Task 1) and video-based action recognition (Task 2).                                                                                                                  
                                                                                                                                                                                              
  ## Requirements                                                                                                                                                                             
                                                                                                                                                                                              
  - Python 3.12   
  - CUDA-capable GPU (tested on RTX 3080 16GB, CUDA 13.0)
                                                                                                                                                                                              
  ## Setup
                                                                                                                                                                                              
  ```bash         
  cd my_basket_tube
  python -m venv .venv                                                                                                                                                                        
  source .venv/bin/activate
  pip install -r requirements.txt                                                                                                                                                             
                  
  Task 1 — Commentary Q&A (Local VLM)                                                                                                                                                         
   
  BNB_CUDA_VERSION=128 python my_basket_tube/inference/player_performance_vlm.py                                                                                                              
                                                                                                                                                                                              
  Requires:
  - HF_TOKEN — HuggingFace token with access to google/paligemma-3b-pt-224                                                                                                                    
  - Trained LoRA adapter at my_basket_tube/models/paligemma_lora/                                                                                                                             
  - Embedding index at my_basket_tube/models/context_5s/embedding_index.pt
                                                                                                                                                                                              
  Task 2 — Video Action Recognition                                                                                                                                                           
                                                                                                                                                                                              
  See notebooks/project.ipynb.                                                                                                                                                                
                                                                                                                                                                                              
  Notes                                                                                                                                                                                       
   
  - Large files (detections_all.csv, tracks.csv, model weights) are excluded from the                                                                                                         
  repo due to size and must be generated by running the pipeline scripts.
  - Set ANTHROPIC_API_KEY as an environment variable if using the API-based synthesis path.
